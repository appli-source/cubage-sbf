# Modèle de reconnaissance vocale

`vosk-model-small-fr-0.22.tar.gz` (42 Mo) : modèle français officiel « small » de Vosk,
Alpha Cephei Inc., licence Apache 2.0 (https://alphacephei.com/vosk/models).

Archive tar.gz du dossier `vosk-model-small-fr-0.22/` tel que distribué (am/, conf/, graph/, ivector/),
format attendu par vosk-browser. Il est téléchargé une seule fois par téléphone lors de la première
activation du mode vocal, puis conservé dans le stockage local du navigateur (IndexedDB) pour un
fonctionnement hors réseau.
