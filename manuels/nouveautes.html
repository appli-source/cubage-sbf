Cubage SBF · Ce qui change
Version 67 (guide du 29 octobre) → version 81 · 1er novembre 2026

À retenir en 30 secondes

1Mode vocal du cubage : dites « billon suivant » après chaque billon. Le billon dicté s'affiche « en cours » et n'est enregistré qu'à ce moment-là (ou avec « grume suivante »). Sans cela, il n'est pas enregistré.
2Corriger, réduire, commenter à la voix sans toucher l'écran : « note diamètre quarante-huit », « note réduction longueur cinquante », « note commentaire gélivure », « précédent » pour rouvrir le dernier billon.
3Nouvelle essence ou qualité ? Bouton + dès la création du lot. Le code est proposé au bureau, qui l'ajoute pour tout le monde.

La mise à jour est automatique : ouvrez l'application avec du réseau, le bas de l'accueil doit afficher Version 81. Rien à réinstaller, vos lots sont conservés.

1. Mode vocal du cubage : nouveau fonctionnement

Avant (version 67)Maintenant (version 81)
EnregistrementChaque billon dicté était enregistré aussitôt.Le billon dicté est en cours, visible à l'écran ; il est enregistré par « billon suivant » (ou « suivant »).
Changer de grume« note suivante »« grume suivante » (ou « suivante », « arbre suivant »), sans « note » ; enregistre aussi le billon en cours.
Corriger« note annule » puis redicter tout le billon.« note diamètre … » ou « note longueur … » corrige un seul champ ; « précédent » rouvre le dernier billon enregistré.
Annuler« note annule » retirait le dernier billon ou rouvrait la grume.« note annule » efface le billon en cours (ou, s'il est vide, le dernier enregistré) ; « note annule grume » vide la grume (ou rouvre la précédente).
RéductionAu clavier seulement.« note réduction longueur cinquante », « note réduction diamètre deux » ; « note annule réduction ».
CommentaireAu clavier seulement.« note commentaire gélivure » (mot de la liste) ou « note commentaire » puis une phrase libre ; « note annule commentaire ».

1Le bloc vocal affiche le billon en cours et rappelle de dire « billon suivant ».
2Le billon se remplit à l'écran : qualité, longueur, diamètre, réduction, commentaire.

Exemple d'une grume de deux billons

« note chêne, cé a, dix par cinquante »Billon en cours : CH, CA, 10 m, Ø 50 (rien d'enregistré)
« billon suivant »Billon 140.1 enregistré, relu à voix haute ; le billon 140.2 s'ouvre
« note cé bé, huit vingt par quarante-deux »Billon en cours : CB, 8,20 m, Ø 42
« note réduction longueur cinquante » · « note commentaire gélivure »Réduction 50 cm et commentaire ajoutés au billon en cours
« note diamètre quarante »Diamètre corrigé : Ø 40
« grume suivante »Billon 140.2 enregistré, grume 140 close, grume 141 ouverte

Exemple rejoué tel quel dans l'application version 81. Les mots de commentaire reconnus par défaut : gélivure, pourriture, roulure, nœuds, courbure, fente, fourche, cœur, aubier, échauffure, bois de réserve (liste modifiable dans Paramètres › Mode vocal).

2. Mode vocal sur pied

  • Pointage par classes : « note tarif onze » change le tarif Chaudé de l'essence en cours ; « terminé » quitte l'écran. Le reste ne change pas (chaque phrase compte une tige).
  • Pied à pied numéroté : le mode vocal est nouveau. Même principe que le cubage : l'arbre se remplit puis « suivant » l'enregistre.
Vous ditesCe qui se passe
« note chêne quarante-cinq par seize »Arbre en cours : CH, Ø 45, hauteur 16 m
« note tronçon six cé a » · « note tronçon quatre » puis « note cé bé »Tronçons 6 m CA puis 4 m CB (du bas vers le haut) ; le reste compte en BI
« note tarif dix » · « note hauteur dix-huit virgule cinq »Tarif Chaudé 10 ; hauteur corrigée à 18,5 m
« suivant » · « précédent »Enregistre l'arbre · rouvre le dernier arbre enregistré
« note annule tronçon » · « note annule arbre »Retire le dernier tronçon · supprime le dernier arbre enregistré

3. Ajouter une essence ou une qualité sur le terrain

+Le bouton + existe maintenant dès la création du lot, dans la fiche « Essences et qualités » du lot et dans la recoupe d'un lot client (il existait déjà sur l'écran de saisie).
✓À la sauvegarde du lot, le code est proposé au bureau. Une fois validé, tous les téléphones le reçoivent avec « Mettre à jour depuis le Sheet » ; en attendant il reste utilisable sur votre téléphone.

4. Import d'inventaire de bûcheron (version 67)

  • Colonne Note (ou Commentaire, Observation, Remarque) reprise dans le commentaire du billon.
  • Les CSV enregistrés par Excel en français (« 8,20 », accents) sont lus correctement ; auparavant « 8,20 » donnait 820 m.
  • Modèle à jour : modele-import-inventaire.xlsx (avec colonne note).

5. Côté bureau

  • Installer le script du Sheet version 3.3 (Apps Script › Gérer les déploiements › Nouvelle version) : sans lui, les codes proposés par les techniciens ne remontent pas.
  • Nouvelle tuile Essences et qualités proposées : valider (avec le mot à dire pour le mode vocal) ou refuser.
  • Les numéros de grumes et de billons ne sont plus transformés en dates par le Sheet (script 3.1) ; les anciennes lignes concernées sont remises en forme à l'affichage dans l'espace Bureau.
  • Mode vocal : la colonne « mots_vocaux » des onglets ESSENCES / QUALITES est désormais bien prise en compte ; à défaut, la colonne « libellé » sert de mot vocal.

6. Point d'attention connu

En dictée pied à pied numéroté, quand on change d'essence à la voix (« note hêtre trente par quatorze »), l'arbre garde le tarif Chaudé de l'essence précédente. Vérifiez le tarif affiché et dites « note tarif … » si besoin.
