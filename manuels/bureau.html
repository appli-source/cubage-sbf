L'essentiel en une page

Le bureau ne cube pas : il équipe les téléphones, diffuse le référentiel (essences, qualités, grilles de prix), consulte les lots des techniciens, valide les ventes et édite les bordereaux. Tout passe par le même lien que les techniciens, ouvert avec une clé bureau sur un ordinateur (Chrome, Edge ou Safari).

Nouveautés depuis la version 63

  • Commentaire par billon saisi au téléphone : nouvelle colonne commentaire dans l'onglet BILLON (créée d'elle-même), repris dans le listing, les exports et les bordereaux (colonne « Réduction »).
  • Longueur fixe par lot (billons de même longueur) : réglage du lot, sans effet sur le Sheet.
  • Mode vocal : mot de départ « note » et rejet des phrases mal comprises, réglables par téléphone.
  • Hors ligne : les téléphones ouvrent leur propre copie de l'application si GitHub est en panne, supprimé ou lent ; une fois installée, l'application demande un stockage persistant (lots et application non effacés en cas de manque de place).
  • Script du Sheet inchangé : version 3.0.

1. Comment c'est construit

Téléphones et postesMémoire du navigateur (IndexedDB)Chaque téléphone travaille hors ligne ; un lot appartient au téléphone qui l'a créé, le Sheet en reçoit une copie à chaque sauvegarde.
Principe : le téléphone est maître de ses lots, le Sheet est la copie de référence du bureau. Le bureau lit, valide les ventes et diffuse le référentiel, mais ne modifie pas un lot de technicien (sauf son point GPS, 5.4).
Si GitHub est indisponible, les téléphones déjà installés continuent de fonctionner sur leur copie ; seules les nouvelles installations, les mises à jour et le premier téléchargement du modèle vocal en dépendent.

2. Le poste bureau

1La tuile Bureau apparaît sur l'accueil dès qu'une clé bureau est configurée (lien de configuration de rôle « bureau »).
2⚙ Paramètres : adresse du script, clé bureau, maintenance du Sheet (clé maître uniquement).

Le poste bureau peut aussi cuber et créer des lots comme un téléphone ; en pratique on l'utilise pour l'espace Bureau.

1Actualiser le stock : lit le Sheet (réseau). La date de la dernière lecture est affichée ; la lecture est conservée sur le poste.
2Stock bord de route : tous les billons connus, en stock, proposés, vendus, recoupés (5.2).
3Lots clients de l'entreprise : ventes transmises par les téléphones, à valider (5.3).
4Lots des techniciens : copies en lecture seule des lots, bordereaux (5.4).
5Lot client multi-techniciens : vente regroupant plusieurs téléphones et chantiers (5.5).
6Clés d'accès et liens de configuration (chapitre 4).
7Grilles de prix communes (5.6).

3. Mise en place et mise à jour du script du Sheet

3.1 Première installation

  1. Dans le Sheet : Extensions › Apps Script, coller le contenu de sync.gs, renseigner les constantes CLE (clé terrain maître) et CLE_BUREAU (clé bureau maître) avec des valeurs longues et secrètes.
  2. Déployer › Nouveau déploiement › Application web : exécuter en tant que moi, accès Tout le monde. Copier l'URL qui se termine par /exec.
  3. Sur le poste bureau : ouvrir l'application, ⚙ Paramètres › URL du script et Clé bureau, puis Charger le référentiel du Sheet.

3.2 Mettre à jour le script

  1. Récupérer sync.gs sur GitHub (la première ligne indique la version), remplacer le code dans Apps Script en conservant vos constantes CLE / CLE_BUREAU.
  2. Déployer › Gérer les déploiements › crayon › Version : Nouvelle version › Déployer. L'adresse /exec ne change pas : rien à refaire sur les téléphones.

Version 3.0 : action setLotGps (point GPS placé depuis le bureau). Les colonnes ajoutées par l'application (proprietaire, grille_client, prix_vente_m3, montant_vente, commentaire…) se créent d'elles-mêmes à la première sauvegarde.

3.3 Mettre à jour l'application

Une modification sur la branche main du dépôt est en ligne en une à deux minutes. Les téléphones la prennent à la prochaine ouverture avec du réseau ; le numéro de version est en bas de l'accueil (actuellement 66). Le mode vocal (vendor/, models/) n'est téléchargé qu'à la première activation.

4. Clés d'accès et équipement des téléphones

Une clé = un technicien (rôle terrain) ou un poste bureau (rôle bureau : valide les ventes, voit tout le stock). L'opérateur attaché à la clé est imposé sur toutes les lignes que ce téléphone envoie : c'est lui qui identifie l'auteur d'un lot.

aNouvelle clé : opérateur (prénom ou initiales), rôle terrain ou bureau, Créer la clé et le lien. Chaque clé existante est listée avec son état, sa date et sa note.
b(capture suivante) Le lien de configuration s'affiche aussitôt : Copier puis l'envoyer au technicien (mail, WhatsApp). Il l'ouvre une fois dans Safari/Chrome puis ajoute l'application à l'écran d'accueil ; sur iPhone il peut devoir coller le lien dans Paramètres.
Fenêtre affichée après la création d'une clé : le lien de configuration à copier et envoyer.
BoutonEffet
Lien de configurationRéaffiche le lien d'une clé (technicien qui réinstalle).
Remplacer (tél. perdu)Crée une nouvelle clé pour le même opérateur et désactive l'ancienne ; envoyer le nouveau lien. Sur le nouveau téléphone : Paramètres › « Récupérer mes lots depuis le Sheet ».
DésactiverLa clé ne permet plus ni sauvegarde ni mise à jour ; les données déjà sur le Sheet restent.
Les clés maîtres du script (CLE, CLE_BUREAU) fonctionnent toujours et ne figurent pas dans l'onglet CLES : ne les diffusez pas. Seule la clé bureau maître peut vider les lots du Sheet.

5. L'espace Bureau

5.1 Actualiser

Commencez toujours par Actualiser le stock : l'espace Bureau travaille sur la dernière lecture du Sheet, conservée sur le poste (consultation possible hors ligne).

5.2 Stock bord de route

1Recherche libre : n° Xylolink, chantier, n° de grume, commune, opérateur, date.
2Statut : en stock, proposés (dans un lot client transmis, à valider), vendus, recoupés, ou tous.
3Essence.

Les billons sont groupés par chantier avec volume et montant (grilles propriétaire des lots). Le total filtré s'affiche au-dessus du tableau.

5.3 Valider les ventes (lots clients de l'entreprise)

✓Ouvrez un lot « transmis au bureau » : volumes, prix, récapitulatif et billons avec leur origine (n° Xylolink, chantier). Valider la vente le passe en vente validée ; Annuler ce lot client l'annule (ses billons repassent en stock).
  • Le technicien voit le nouveau statut à sa prochaine « Mise à jour depuis le Sheet ».
  • Un billon vendu ne peut plus être proposé à un autre client ni supprimé sur le téléphone ; dans le stock il passe en « vendus ».

5.4 Lots des techniciens et bordereaux

↻Charger / Actualiser les lots depuis le Sheet : copies en lecture seule des lots de tous les téléphones, avec l'opérateur, le type (cubage, sur pied), la commune et le volume. Recherche par opérateur, n° Xylolink, chantier, commune, date.
1Bordereau propriétaire : sans prix ou avec prix HT de la grille propriétaire.
2Bordereau client : choisir le sous-lot (ou tout le lot), sans ou avec prix HT de la grille client.
3Point GPS : le placer ou le corriger sur la carte depuis le bureau ; il est écrit sur le Sheet (script 3.0).

Listing, récapitulatif (achat / vente / marge), PDF interne et Excel sont aussi disponibles. Les modèles de bordereaux sont présentés au chapitre 7.

Un point GPS placé depuis le bureau est écrasé si le technicien renvoie ensuite ce lot depuis son téléphone (qui n'a pas le point). À faire sur des lots terminés, ou demander au technicien de le placer lui-même.

5.5 Lot client multi-techniciens (ramasse)

Après chargement des lots des techniciens : Bureau › Lot client multi-techniciens › + Nouveau lot client. Même fonctionnement qu'au téléphone : client, référence, grille, puis billons par numéro, plage ou liste collée, recoupes et prix de vente. Les billons peuvent venir de plusieurs téléphones et plusieurs chantiers ; le lot est validé directement avec la clé bureau.

⇄Lot « Scierie du Perche » : billons 501 à 506 du lot de QS (Forêt de Bercé) et 125 à 130 du lot de JCF (Bois de la Touche). La colonne Origine indique le chantier de chaque billon.
Bordereau de réception d'une ramasse : le chantier d'origine de chaque billon et un lien GPS par chantier figurent sur le document.

5.6 Grilles de prix communes

aListe des grilles (type grumes ou sur pied, nombre de lignes). + Grille commune grumes ou + Grille commune sur pied pour en créer une.
bÉdition : nom, puis une ligne par règle (+ Ligne) — essence, qualité, Ø min, Ø max, prix €/m³. Enregistrer sur le Sheet publie la grille (onglet GRILLES) ; les techniciens la reçoivent à leur prochaine mise à jour.

Une grille commune supprimée disparaît des téléphones ; les copies faites dans les lots sont conservées. Convention de nommage conseillée : « Achat … » pour les grilles propriétaire, « Vente … » pour les grilles client, avec l'année ou la saison.

6. Grilles de prix : propriétaire, client, catalogue et copies

NiveauGrille propriétaire (achat)Grille client (vente)
Lot de cubageUne grille : catalogue ou copie propre au lotUne grille par défaut : catalogue ou copie propre au lot
Sous-lot—Facultative, l'emporte sur celle du lot
Lot client—Grille du client, copiée dans le lot et complétée
  • Catalogue = grilles communes du Sheet ou créées sur le téléphone. Modifier une grille du catalogue change tous les lots qui l'utilisent sans copie.
  • Copie = grille figée dans le lot (ou le sous-lot), modifiable pour ce lot seul : prix négocié, client qui change son prix lot par lot.
  • Règles : essence, qualité, Ø min / Ø max (bornes incluses, sur le diamètre cubé), prix €/m³ ; champ vide = toutes ; la ligne la plus précise l'emporte. Un billon sans règle apparaît « sans prix » et n'entre pas dans les montants.

9. Maintenance et dépannage

9.1 Sauvegardes

  • Le Sheet est sauvegardé avec le Drive SBF (historique des versions + sauvegarde journalière). Faire une copie du Sheet avant toute purge.
  • Chaque téléphone peut produire une copie de secours complète : Paramètres › Exporter tout (JSON) ; Importer un fichier JSON la restaure.

9.2 Vider les lots du Sheet (fin de saison, test)

Paramètres du poste bureau (clé bureau maître uniquement) › Maintenance du Sheet › Vider les lots du Sheet…, confirmation par le mot VIDER. Supprime lots, billons et lots clients de tous les téléphones sur le Sheet ; essences, qualités, grilles et clés sont conservées. Les téléphones gardent leurs lots et les renverront à leur prochaine sauvegarde : les archiver ou les supprimer sur les téléphones avant.
